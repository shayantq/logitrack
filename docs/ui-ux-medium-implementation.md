# تکمیل رابط پنل و اصلاح صف گزارش‌ها

تاریخ: ۱۱ نوامبر ۲۰۲۶

- رنگ متن موفقیت، هشدار، خطا و اطلاعات در تم روشن تیره‌تر شد تا روی زمینهٔ ملایم و سطح کارت خوانا باشد. دکمه و شمارندهٔ خطا در تم تاریک رنگ متن مستقل دارند. آزمون مرورگر نسبت کنتراست توکن‌های متن، وضعیت‌ها، دکمه‌ها و حاشیهٔ کنترل‌ها را در هر دو تم اندازه می‌گیرد؛ این بررسی ادعای انطباق کامل سایت با WCAG نیست.
- ارتفاع خطوط فارسی و عنوان‌ها منظم شد؛ سربرگ جدول از متن ریز و کم‌رنگ به متن ۱۴پیکسلی با وزن بیشتر تغییر کرد. متن راهنمای ورودی مشترک دیگر با opacity کم‌رنگ نمی‌شود.
- اسکلت مقصد برای فهرست، داشبورد، گزارش و فرم تنظیمات متفاوت است. انتظار ورود اولیه به پنل هم اسکلت دارد؛ انتظار عملیات دکمه همچنان وضعیت همان دکمه را نشان می‌دهد.
- روی دستگاه لمسی، دکمه‌ها و کنترل‌های مشترک، گزینه‌های Select و انتخاب‌های بخش‌بندی‌شده حداقل ارتفاع ۴۴ پیکسل دارند. حذف فیلتر هدف واقعی مستقل دارد؛ روی دسکتاپ حداقل ۲۴ و روی صفحهٔ لمسی ۴۴ پیکسل است.
- در حالت کاهش حرکت، shimmer مخفی می‌شود، تکرار انیمیشن قطع می‌شود و دکمه با لمس کوچک نمی‌شود. ساختار اسکلت بدون حرکت باقی می‌ماند.
- Kombu روی نسخهٔ سازگار با Redis فعلی ثابت شد. پیش از تست E2E و پایان استقرار، worker باید از مسیر واقعی broker پاسخ ping بدهد. خطاهای شبکهٔ مرورگر نیز به گزارش شکست E2E اضافه می‌شوند.

انتشار فقط پس از موفقیت CI همان commit و بررسی سلامت سرور انجام می‌شود. هیچ مهاجرت دیتابیس اضافه نشده است. تحقیق با کاربران واقعی، سنجش صدک ۷۵ CLS و آزمون کامل صفحه‌خوان همچنان کارهای مستقل آینده‌اند.

بررسی محلی: ساخت Docker شامل TypeScript/Vite و Ruff موفق بود؛ ۱۴ سناریوی UX شامل نسبت رنگ توکن‌ها در هر دو تم، اندازهٔ کنترل لمسی و توقف حرکت طولانی موفق بودند. اسکن pip-audit با استثناهای موجود پروژه یافتهٔ جدیدی نداشت؛ پاسخ worker از مسیر broker نیز تأیید شد. نتایج کامل انتشار در اجرای GitHub Actions همان commit ثبت می‌شوند.

دو تلاش CI پیش از شروع سناریوهای مرورگر با خطای DNS مخزن Ubuntu در نصب وابستگی‌های سیستم شکست خوردند. اجرای مرورگر به image رسمی Playwright نسخهٔ 1.49.1 روی Noble، ثابت‌شده با digest، منتقل شد؛ نسخه با package-lock تست‌ها یکسان است. همان تست‌ها، خروجی خطا، خلاصهٔ GitHub و artifactها حفظ می‌شوند. مرجع: [مستند رسمی اجرای Playwright در Docker](https://playwright.dev/docs/docker). مجموعهٔ کامل محلی نیز با ۵۱۴ از ۵۱۴ بررسی موفق پایان یافت.

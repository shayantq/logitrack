# امنیت پسینه — وضعیت، تغییرات و برنامه

این سند نتیجه‌ی بررسی یک گزارش امنیتی بیرونی (SEC-01 تا SEC-21 و DB-01 تا DB-07) در برابر کد واقعی مخزن است.
آن گزارش فقط از منابع عمومی نوشته شده بود؛ هر مورد اینجا با مدرک از کد یا تست سنجیده شده است.

## ۲. تغییرات فاز ۱

- **بستن امن در سرور اصلی** — با `APP_ENV=production` برنامه بدون `SECRET_KEY` امن (حداقل ۳۲ نویسه و غیرنمونه) یا با رمز نمونه دیتابیس بالا نمی‌آید. بررسی پیش از فعال‌سازی:
  `docker compose run --rm --no-deps web python -m app.security_preflight` — فقط «PASS/FAIL» چاپ می‌کند، هرگز مقدار.
  در سرور اصلی `/docs`، `/redoc` و `/openapi.json` بسته‌اند. توسعه و تست مثل قبل.
- **لاگ بدون راز** — پیامک و ایمیلِ ارسال‌نشده فقط با گیرنده نیمه‌پنهان (`0912***1087`) و طول متن در لاگ می‌آید. توکن لینک‌های مخفی (دمو، پشتیبانی، دعوت، نظرسنجی) در لاگ دسترسی با `***` جایگزین می‌شود.
- **ورود** — شمارش تلاش ناموفق و قفل با UPDATE شرطی (اتمی)؛ زمان پاسخ برای نام کاربری ناموجود و رمز اشتباه یکسان؛ بیش از ۳۰ تلاش ناموفق در ۱۵ دقیقه از یک IP ورود از آن IP را موقتاً می‌بندد.
- **محدودیت تعداد درخواست** — در Redis و مشترک بین همه پروسس‌ها؛ اگر Redis در دسترس نباشد شمارش در حافظه ادامه می‌یابد.
- **بازیابی رمز** — مصرف کد یک‌باره و اتمی؛ شمارش تلاش اتمی.
- **خروجی اکسل و CSV** — متنی که با `= + - @` یا Tab شروع شود به‌صورت متن ذخیره می‌شود، نه فرمول.
- **هدرها** — `X-Content-Type-Options`، `X-Frame-Options: DENY`، `Referrer-Policy`، `Permissions-Policy`، و `Cache-Control: no-store` روی ورود، بازیابی و لینک‌های توکن‌دار. CSP فعلاً فقط در حالت گزارش (چیزی را مسدود نمی‌کند).
- **وابستگی‌ها** — FastAPI، Starlette، anyio، certifi، dnspython، pyasn1، python-dotenv، pytest، react-router و vite به نسخه رفع‌شده رفتند؛ pip از image نهایی حذف شد. آسیب‌پذیری‌های شناخته‌شده پایتون از ۱۸ به ۲ رسید (هر دو بدون نسخه رفع‌شده، با استثنای مستند در `security/pip-audit-waivers.txt`)؛ npm اجرایی و image نهایی (Trivy) صفر.
- **CI** — مرحله «Security scan»: pip-audit، bandit، npm audit، gitleaks روی کل تاریخچه و Trivy روی image نهایی. ابزارها با image داکرِ نسخه و digest ثابت. یافته شدید استقرار را متوقف می‌کند.
- **تست‌ها** — `tests/unit/test_security_hardening.py` و `tests/api/test_security_api.py`.

بررسی تاریخچه git با gitleaks هیچ رازی پیدا نکرد.
